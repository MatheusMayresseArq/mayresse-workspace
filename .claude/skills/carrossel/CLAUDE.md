# .claude/skills/carrossel/

Skill de criação de carrosséis para Instagram das 3 marcas da Mayresse.

## Arquivos

- `SKILL.md` — instruções completas da skill (fluxo, regras, checkpoints)
- `references/design-carrossel.md` — estilo visual ativo (minimalista por padrão)
- `references/design-minimalista.md` — layout clean, espaço em branco, elegante
- `references/design-elaborado.md` — texturas, composições ousadas
- `references/design-tweet.md` — simula post do Twitter
- `references/badge-verificado.svg` — badge azul pra estilo tweet

## Como trocar o estilo visual

Pedir: "muda o estilo do carrossel pra elaborado" — o Claude copia o arquivo correspondente pra `design-carrossel.md`.

## Saídas por marca

- Mayresse Arquitetura → `conteudo/mayresse-arquitetura/carrosseis/[tema]/`
- Mayresse Lima → `conteudo/mayresse-lima/carrosseis/[tema]/`
- Inside Mayresse → `conteudo/inside-mayresse/[tema]/`
