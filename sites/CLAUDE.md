# sites/

Landing pages e sites gerados para as marcas da Mayresse.

## Organização

Criar uma subpasta por projeto: `sites/nome-do-projeto/`

Cada projeto contém o HTML gerado e, se publicado, o link da URL.

## Publicação

Sites são publicados via Cloudflare Pages. Ver `templates/ferramentas/catalogo.md` para instruções de deploy.
Usar a skill `/publicar-site` quando disponível.
